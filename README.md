## ✨ Implemented Features
- **User Authentication:** Secure user registration, login, and session tracking.
- **Create (C):** Add custom daily habits with tracking intervals.
- **Read (R):** A personalized dashboard displaying current active habits and completion statuses.
- **Update (U):** Interactive checklist items that increment streak values upon completion.
- **Delete (D):** Absolute entry removal from the active tracker.
